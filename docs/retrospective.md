# Project Retrospective

## What Went Well?
One thing that went well during this project was staying organized through documentation and planning. Creating a project scope statement early helped keep the project focused and prevented scope creep. I also improved my HTML and CSS skills significantly while developing the website.

## What Went Wrong?
The biggest challenge was balancing time management with learning multiple technical concepts at once. At times, troubleshooting HTML and CSS errors slowed progress, especially while managing other responsibilities outside of class.

## What Would I Do Differently Next Time?
In future projects, I would start earlier and create a more detailed schedule for each milestone. I would also test website features more frequently instead of waiting until later stages. This project taught me the importance of planning, accountability, and continuous learning.
