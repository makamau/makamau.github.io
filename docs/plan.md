# Project Plan

## Risk Analysis (TAME Framework)

| Risk | Strategy | Explanation |
|------|-----------|-------------|
| Confusing project requirements | Mitigate | Review instructions carefully and compare work against rubric |
| Time management issues | Avoid | Break project into smaller tasks with deadlines |
| Website styling errors | Transfer | Use online documentation and tutorials for support |
| GitHub publishing issues | Mitigate | Test GitHub Pages before final submission |
