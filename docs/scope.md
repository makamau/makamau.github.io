# Project Scope Statement

## Project Title
Driving with AI Website

## Purpose
The purpose of this project is to create a professional website for a fictional trucking company called Driving with AI. The website will provide information about transportation services and demonstrate web development and project management skills.

## Objectives
- Build a two-page responsive website
- Publish the project on GitHub
- Apply HTML and CSS concepts learned in class
- Create professional project documentation

## Deliverables
- Homepage (`index.html`)
- About page (`about.html`)
- Shared stylesheet (`style.css`)
- Public GitHub repository
- Complete project documentation

## Success Criteria
The project will be considered successful if:
- All pages function correctly
- Navigation links work properly
- Styling is consistent across pages
- The repository is public and organized
- Documentation files are complete

## Exclusions
The project will NOT include:
- Online payment systems
- Customer login accounts
- Real trucking dispatch software
- Database integration
- Mobile applications
