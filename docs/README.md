# Driving with AI

Driving with AI is a fictional trucking and logistics company website created as a final project for this course. The project demonstrates skills in project management, HTML, CSS, GitHub documentation, and website planning.

## Live Website
https://github.com/makamau

## Project Purpose
The purpose of this project is to design a professional website for a trucking company that highlights transportation services, technology integration, and customer reliability.

## Repository Contents
- `index.html` – Homepage
- `about.html` – About the company
- `style.css` – Shared website styling
- `docs/scope.md` – Project Scope Statement
- `docs/plan.md` – Project plan and risk analysis
- `docs/retrospective.md` – Project retrospective reflection

- HTML5
